# Copy cleanup workflow

1. Open the **[Decanti copy cleanup review](https://cursor.com/canvas/store-a86d658e-90e7-4c15-a83c-518fdc59ca37/9134040a-ef3b-4845-949d-5f7bb17e3f90)** canvas (or from the chat canvas link).
2. For each item, choose **Approve cleanup** or **Keep as-is**. Verdicts persist on the canvas.
3. When finished, click **Apply in agent chat** or tell the agent the approved IDs (e.g. `A1, B2, C4`).
4. The agent implements only approved items on `cursor/copy-cleanup-review-cd41` in a single PR.

Canonical item list: `copy-cleanup-manifest.json` in this folder.
